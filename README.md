# Nixora AI

Nixora AI is an advanced coding and productivity assistant with code generation, live preview, debugging, and Android APK project builder.
Intelligence Without Limits.

## Features

- **General Chat & Knowledge**: Powered by Google's Gemini models.
- **Code Studio**: Built-in coding assistant with live preview (HTML/CSS/JS) and multiple languages supported.
- **Android APK Builder**: Scaffolds Jetpack Compose Android Apps.
- **Settings & Profile**: Customizable AI persona and UX settings (Themes, Speech-to-text, and Text-to-speech).

## Tech Stack

- Frontend: React, TypeScript, Tailwind CSS, Vite
- Backend: Node.js, Express, TypeScript, Google Gemini API SDK

## Getting Started

1. Clone the repository.
2. Install dependencies: `npm install`
3. Create a `.env` file from `.env.example` and set `GEMINI_API_KEY`.
4. Start development server: `npm run dev`

## Deployment

The app provides a Dockerfile or can be directly hosted on modern cloud services (Vercel, Render) with environment variables.
